## The entry

> The spare button sewn inside every new shirt: a backup that has never once been called up, and will outlive the shirt it came with.

Character count: **131** (single line, within the 1–200 character limit).

## How it works

`main.py` holds the review as a constant, validates it (non-empty, single
line, 1–200 characters), and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/boring-object-review-output python3 main.py
cat /tmp/boring-object-review-output/entry.txt
```
